## Définition du DevOps
Le DevOps c'est quand les développeur et les equipes  qui gérent les serveurs ne travaillent plus chacun de leur côté.Mais travaillent ense;ble sur un projet du début à la fin, dans le but de sortir des logiciels plus vite ,plus souvent avec moins de bug, en automatisant un maximum de tâches  
## Commande Git utilisées
- `git init` : initialiser le dépôt Git.
- `git status` : vérifier l'état des fichiers.
- `git add .` : ajouter tous les fichiers au suivi Git.
- `git commit -m "Premier commit"` : enregistrer les modifications.
- `git remote add origin ...` : relier le projet local au dépôt GitHub.
- `git branch -M main` : renommer la branche principale en `main`.
- `git push -u origin main` : envoyer le projet sur GitHub.
